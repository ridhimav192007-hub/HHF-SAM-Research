 HHF-SAM: Rectal Cancer Segmentation

Project Overview
This project aims to implement the HHF-SAM architecture for rectal cancer segmentation from medical CT images, based on the research paper *Rectal Cancer Segmentation via HHF-SAM: A Hierarchical Hypercolumn-Guided Fusion Segment Anything Model*.

 Current Progress
- SAM-B Encoder with LoRA and Adapter — Implemented and initially tested
- Multi-scale Hypercolumn Processing Module (MHPM) — Implemented and initially tested
- Hierarchical Fusion Module (HFM) — Pending
- Progressive Hierarchical Fusion Decoder (PHFD) — Pending
- Model integration, training, and evaluation — Pending

 Project Files
- `models/encoder.py` — Encoder implementation
- `models/mhpm.py` — MHPM implementation
- `models/test_encoder.py` — Encoder test
- `models/test_mhpm.py` — MHPM test
